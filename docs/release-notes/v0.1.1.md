# ConTicx v0.1.1 — venue-time display fix

Patch release for [v0.1.0](v0.1.0.md). No new features.

## Fixed

- **Event dates and times now show in the venue's time zone.** v0.1.0
  formatted them in the server's default zone, so the UTC-hosted demo
  displayed every time four hours late, and Indie Echoes (Sun Sep 20,
  8:00 PM in Brooklyn) appeared as Mon Sep 21 at 12:00 AM. Each catalog
  event now carries an IANA `venueTimeZone` (`America/New_York`), and the
  home cards, event pages, and tickets format the date, weekday, doors time,
  and show time in that zone, independent of the server or browser. Event
  instants are unchanged, and the calendar file still carries the exact UTC
  start.

## Verification

- New regression tests (`tests/unit/venue-time.test.ts`): formatting and
  rendered pages under a UTC default zone, an event on the next UTC date,
  daylight-saving transitions, catalog zone/offset consistency, and the
  calendar instant.
- Lint, typecheck, the full automated test suite, and a production build.

## Upgrade notes

None. No configuration, dependency, or API change.
